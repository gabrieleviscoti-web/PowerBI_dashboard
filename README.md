# Superstore Sales Dashboard

## Project Objective
This project analyzes the Sample Superstore dataset to provide a clear and actionable overview of business performance.
The dashboard focuses on:

- sales trends

- profit analysis

- category and segment performance

- regional insights

- discount impact

- customer and product profitability

I performed data cleaning, modeling, and visualization in Power BI.

## Dataset Description
The Sample Superstore dataset contains detailed information about orders, products, customers, and regions.
It is widely used for analytical and visualization practice.

### Main fields

| Main fields| Description | 
|------------|-------------|
| Order ID     | Unique order identifier       | 
| Product name | Product sold      |
| Category/Sub-category | Product classification       | 
| Sales     | Revenue generated       | 
| Profit | Profit per order      |
| Quantity | Units sold       | 
| Discount    | Discount applied       | 
| Region | Geographic region      |
| Order date  | Date of purchase       | 



## Key Metrics (KPI)
The dashboard includes:

- Total Sales

- Total Profit

- Profit Ratio

- Average Discount

- Order Count

- Year-over-Year Growth

- Top Categories / Sub‑Categories

- Top Customers

- Regional Sales & Profit

- Monthly Trend Analysis

- KPI definitions

 ## Dashboard Visuals 
The dashboard contains:

- Line Chart — monthly sales & profit trends

- Bar Chart — category and sub‑category performance

- Map Visualization — regional breakdown

- Scatter Plot — discount vs profit relationship

- KPI Cards — main indicators

- Interactive Table — detailed order-level view

- Slicers — year, region, category, segment

- Effective visuals

## Insights & Findings
Key insights discovered through the dashboard:

- Technology category drives the highest profit

- High discounts significantly reduce profit margins

- The Consumer segment generates the largest sales volume

- Regional performance varies strongly, with some areas underperforming

- Certain products contribute disproportionately to total profit

- Monthly trends show clear seasonality and growth patterns

- Insight analysis



## Final Outcome
This dashboard provides a complete analytical overview of the Sample Superstore dataset, enabling:

- performance monitoring

- identification of trends and anomalies

- category and regional analysis

- data-driven decision making
